# US LLC Compliance & Formation Tracker (2026)

Welcome to the official documentation for **US LLC Compliance Tracker**, an open-source technical reference and CLI toolkit built for international founders, remote SaaS builders, and cross-border digital entrepreneurs.

Maintaining a US Limited Liability Company (LLC) as a non-US resident requires navigating statutory state renewal deadlines, annual report fees, registered agent requirements, and mandatory IRS filings (such as Form 5472 and Form 1120). This documentation consolidates statutory requirements into an actionable, transparent guide.

## 📦 Python CLI Quickstart

Install or clone the repository to run the local statutory fee and deadline calculator:

```bash
git clone https://github.com/reituman602/us-llc-compliance-tracker.git
cd us-llc-compliance-tracker
python tracker.py --state wyoming
```

Sample CLI output:
```text
=== Wyoming LLC Compliance Profile ===
Initial Filing Fee:    $100
Annual Report Fee:     $60
Due Date:              First day of anniversary month
3-Year Base Cost:      $280
Privacy Rating:        High (Members not publicly listed)
```
